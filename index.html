How it works

  • Declared runtime profile: html-canvas/1.
  • Editable inputs are mapped through the template parameter schema and preset to its existing animation project.
  • The declared duration policy follows the current content; the package plan determines final timing.

The documented output is 1920 × 1080, 60 fps. The public demo is 108 seconds. Use the actual package parameter bounds; extra materials do not automatically create extra scenes. Current native media and complete-scene duration choices are described precisely in CURRENT-MEDIA-CLOCK.md; unrelated engine/layout changes remain unsupported. Unlisted whole-brand graphics, new layouts or arbitrary engine/scene logic edits. Native current media uses only the declared windows and complete-scene clock contract.
